company-canteen

Documentation

Phase-by-phase technical documentation for the company canteen ordering system. Each phase builds on the last, from authentication to real-time notifications.

01

Authentication

JWT-based login and registration with BCrypt password hashing, role-based access control (Employee / Admin), and a React auth context with protected routes.

AuthController JWT Bearer BCrypt AuthContext
02

Menu & stock management

Admin CRUD for menu items with categories, daily stock control with date-specific quantities, and the today's menu endpoint that employees see.

MenuController StockController DailyStock DateOnly
03

Ordering flow

End-to-end ordering with an in-memory cart, atomic stock decrement on placement, a status state machine (Placed → Preparing → Ready → Collected), employee order history, and a kitchen kanban board.

OrderController 7 endpoints Kitchen kanban Stock atomicity
04

Order-ready notifications

Polling-based toast notifications that alert employees when their order moves to “Ready”. Uses a custom React hook with a ref-based status map and auto-dismissing toasts.

useOrderNotifications Toast.tsx 10s polling SignalR planned
05

AI chat ordering

Conversational ordering via Claude Haiku 5.5 with an agentic tool-use loop. A generic ClaudeApiService handles the API, while ChatService defines tools and business logic — following the V3 separation pattern.

ClaudeApiService ChatService Tool use Haiku 5.5
06

Agentic loop & tool calling — interview guide

Comprehensive interview prep covering what an agentic loop is, why it's the hardest AI integration pattern, code deep-dive with annotations, 12+ interview Q&A, design patterns, and comparison to RAG & MCP.

Interview prep Design patterns Tool calling vs RAG vs MCP
07

Text-to-SQL — interview guide

When not to use tool calling: Claude generates SQL from natural language for admin analytics. Covers architecture, security layers, annotated code walkthrough, 12+ interview Q&A, and comparison to tool calling & RAG.

Interview prep Text-to-SQL Security deep-dive
08

SSE streaming

Real-time token-by-token streaming from Claude through the .NET backend to the React frontend using Server-Sent Events. Text deltas, tool-start, and tool-done events stream as they happen — with the agentic loop running between streaming rounds.

IAsyncEnumerable AsyncGenerator text/event-stream 4-layer architecture
09

Multi-tenant architecture

Company-scoped data isolation with three roles (User, CompanyAdmin, SuperAdmin). Every entity carries a CompanyId, every query filters by it, and a SuperAdmin dashboard manages all companies.

CompanyId on JWT 3 roles Company-scoped AI Shared database
